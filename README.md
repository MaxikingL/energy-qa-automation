# Energy QA Automation Platform

A portfolio project focused on designing and developing a scalable test automation framework for an energy monitoring web application, inspired by real-world enterprise QA practices.

**Technology Stack:** TypeScript, Playwright, Node.js, GitHub Actions, and Allure Reports.

**Project Objectives:**
- Design maintainable UI test automation using Page Object Model (POM).
- Develop structured functional and end-to-end test scenarios.
- Implement reusable fixtures, test utilities, and test data management.
- Explore API testing where authorized and supported.
- Integrate automated test execution with CI/CD pipelines.
- Generate test execution reports and analyze failures.

The project follows enterprise QA automation principles and emphasizes maintainability, reliability, and test architecture.
